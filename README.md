# The Eleven C's — Agent Skills

Eleven skills that run the instruments from *The Eleven C's of Commercial Real Estate Success* by Jason Blackburn with Rex Blackburn.

Each one matches a chapter. Install what you need, ignore the rest.

---

## Install

Copy and paste this to your assistant:

> Install the skills from https://github.com/[ORG]/eleven-cs-skills — download the repo, and put each folder inside `skills/` into my skills directory.

That's it. You don't need to know what a repo is.

To install just one, name it:

> Install the `c06-credibility` skill from https://github.com/[ORG]/eleven-cs-skills

## Where to start

Two, in this order:

**`c01-commitment`** — ten minutes. One honest word written down.
**`c05-contacts`** — build the ledger once, then just talk to it every Friday.

That's the whole first week. The other nine can wait for a quarter you actually have.

If you want to see what this is before installing anything, start with **`c04-capabilities`**. It runs the lookup on you and gives you a number. Most advisors find it uncomfortable, which is the point.

## How to use them

Talk normally. The skills trigger on what you're actually doing:

- *"I just closed the Rayford building"* → the deposit writer starts asking about the deal
- *"Here are the six people I talked to this week"* → the ledger formats them
- *"Should I chase this one?"* → the eight checks run
- *"Is $500K realistic for next year?"* → the backward trace runs

You don't have to remember which skill does what. Describe the situation.

---

## What these will not do

**They will not invent numbers.** No industry benchmarks that can't be sourced, no statistics nobody can trace, no outcome better than what you actually got. If a skill can't fill something in, it tells you which piece is missing and stops.

That constraint is deliberate and it comes from the book: an inflated record is worse than a thin one, because the whole value of a record is that it's checkable.

**They will not do the producer-only work.** Qualifying, negotiating, and the first call to a new relationship stay yours at every staffing level, human or otherwise. These skills draft, audit, and count. They don't decide and they don't pick up the phone.
